# PCAT PlantCam สำหรับ ESP32-S3

ระบบวัดพื้นที่พุ่มพืชจากภาพมุมบนด้วย ESP32-S3 N16R8 และกล้อง OV5640 เปิดเว็บบนบอร์ดเพื่อจัดภาพก่อนถ่าย กดหนึ่งครั้งเพื่อบันทึกภาพ JPEG สามรูปลง microSD โมเดล FOMO ประมวลผลบนบอร์ดเพื่อหาตำแหน่งต้น จากนั้นโปรแกรมวัดสัดส่วนพื้นที่สีเขียวรอบตำแหน่งที่พบและเปรียบเทียบกับค่าก่อนหน้า

## ผลทดสอบโมเดล v2

| รายการ | ผล |
| --- | --- |
| ชุดฝึก / ชุดทดสอบ | 51 / 13 ภาพ |
| Precision / Recall / F1 ของคลาส `plant` ใน Edge Impulse | 0.75 / 0.75 / 0.75 |
| เวลาเรียกโมเดล int8 บน ESP32-S3 N16R8 | เฉลี่ย 2,434 มิลลิวินาทีต่อภาพ จาก 4 ภาพ ช่วง 2,433–2,434 มิลลิวินาที |
| ขนาดโมเดล int8 ตามที่ Studio ประมาณ / RAM สำหรับ tensor arena | 54.9 KB / 149.856 KB |

เวลาที่วัดเริ่มก่อนเรียกโมเดลและสิ้นสุดเมื่อโมเดลคืนผล จึงไม่รวมการถ่าย JPEG การเขียน microSD และการนับพิกเซลสีเขียว ตัวเลข RAM เป็นขนาดพื้นที่ทำงานของโมเดลที่ระบุในโค้ดส่งออก ไม่รวมกล้อง เว็บ และหน่วยความจำส่วนอื่นของเฟิร์มแวร์

การทดสอบบนบอร์ดบันทึกครบชุดแรกสามรูปและรัน AI ได้โดยไม่รีสตาร์ต โมเดลรายงาน `plant_not_found` ในภาพที่อ่านผลได้ จึงยังต้องทดลองวัดพุ่มกับต้นจริง เฟิร์มแวร์ประมวลผลทีละภาพก่อนถ่ายรูปถัดไป เวลาระหว่างภาพในโหมด AI จึงยาวกว่า 1 วินาที

## ติดตั้งและใช้งาน

1. ใช้ Arduino IDE กับ Arduino-ESP32 3.3.12 เลือก **ESP32S3 Dev Module**, Flash **16MB**, **OPI PSRAM** และพาร์ทิชัน **16M Flash (3MB APP/9.9MB FATFS)** (รองรับ OTA)
2. ติดตั้ง [Arduino Library ของโมเดล int8 v2](model/plant_fomo_int8_arduino_v2.zip) ผ่าน **Sketch → Include Library → Add .ZIP Library**
3. เปิด [LeafPhotoRecorder.ino](LeafPhotoRecorder/LeafPhotoRecorder.ino) แล้วอัปโหลด สำหรับช่อง USB-UART ตั้ง **USB CDC On Boot: Disabled** จากนั้นเปิด Serial Monitor ที่ 115200 baud
4. ใส่ microSD แบบ FAT32 ต่อ Wi‑Fi ชื่อ `PlantCam-<MAC>` แล้วเปิด [หน้าเว็บบนบอร์ด](http://192.168.4.1) เพื่อดูภาพตัวอย่างและสั่งถ่าย
