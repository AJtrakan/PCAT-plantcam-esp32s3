# กดถ่าย 3 ภาพ ดูผ่านเว็บ และวัดพุ่มแบบ AI-first

เปิด `LeafPhotoRecorder.ino` ใน Arduino IDE สเก็ตช์นี้ใช้ ESP32-S3 CAM N16R8 กับ OV5640 หน้าเว็บแสดงภาพตัวอย่างสดสำหรับจัดตำแหน่ง เมื่อกดปุ่มหนึ่งครั้งจะถ่าย JPEG 320×240 จำนวน 3 รูป กะพริบ GPIO2 หลังบันทึกแต่ละรูป และแสดงภาพล่าสุดกับ 12 ภาพล่าสุดจาก SD โมเดล FOMO หาตำแหน่งต้นก่อนคำนวณพื้นที่พุ่ม รุ่น v2 ใช้เวลารัน AI ประมาณ 2.43 วินาทีต่อภาพ จึงใช้เวลาระหว่างรูปมากกว่า 1 วินาทีในโหมด AI

1. ใส่ microSD แบบ FAT32 ในช่องบนบอร์ดขณะปิดไฟ โปรแกรมไม่ฟอร์แมตการ์ดอัตโนมัติ
2. เลือก **ESP32S3 Dev Module**, **Flash Size 16MB**, **PSRAM OPI PSRAM** ใช้ Arduino-ESP32 3.x เมื่อเปิด AI ให้เลือก **Huge APP (3MB No OTA)**
3. สำหรับช่อง **USB-UART** ให้เลือกพอร์ตของช่องนี้และตั้ง **USB CDC On Boot: Disabled** เพื่อให้ Serial Monitor ออกทาง UART หากใช้ช่อง **USB-OTG** ให้เลือก **USB CDC On Boot: Enabled**
4. กด Verify แล้ว Upload เปิด Serial Monitor ที่ **115200 baud** และกด RST หากต้องการดูข้อความตั้งแต่เริ่ม
5. ต่อโทรศัพท์หรือคอมพิวเตอร์เข้ากับ Wi-Fi แบบเปิดชื่อ `PlantCam-xxxx` โดยไม่ใช้รหัสผ่าน แล้วเปิด `http://192.168.4.1`
6. ดูภาพตัวอย่างสดเพื่อจัดตำแหน่ง ภาพอัปเดตประมาณทุก 0.8 วินาทีและไม่บันทึกลง SD
7. กด **ถ่าย 3 รูป** แล้วรอจนสถานะกลับเป็น **พร้อมถ่าย** จึงกดรอบต่อไป ภาพตัวอย่างจะหยุดชั่วคราวระหว่างถ่ายชุด
8. ภาพเก็บที่ `/lettuce/run_XXXXXXXX/00000/IMG_00000001.jpg` สร้างโฟลเดอร์รอบใหม่เมื่อรีเซ็ต และแบ่งโฟลเดอร์ย่อยทุก 1,000 ภาพ
9. ก่อนถอด SD ให้รอให้ชุดถ่ายเสร็จ แล้วปิดไฟบอร์ดก่อนถอดการ์ด

ผังขาใช้แบบ Freenove ที่ตรงกับรูปแบบบอร์ดในโปรเจกต์เดิม SDMMC 1-bit ใช้ CLK 39, CMD 38 และ D0 40 หาก mount ไม่ผ่าน ให้ตรวจผังบอร์ดจริงกับผู้ขาย [คู่มือ microSD ของ Freenove](https://docs.freenove.com/projects/fnk0086/en/latest/fnk0086/codes/tutorial/4_Read_and_Write_the_SDcard.html)

GPIO2 ตั้งเป็น Active HIGH หากบอร์ดของคุณใช้ไฟแบบ Active LOW ให้เปลี่ยน `LED_ON` เป็น `LOW` ถ้าต่อ LED ภายนอกแบบ Active HIGH ให้ใช้ GPIO2 → ตัวต้านทาน 330 Ω → ขาแอโนด LED และต่อขาแคโทดลง GND

เมื่อเขียนไม่สำเร็จ โปรแกรมจะหยุดชุดถ่ายและแจ้งบนเว็บกับ Serial ให้ตรวจพื้นที่หรือเสียบการ์ดใหม่ขณะปิดไฟ เครือข่ายเป็นแบบเปิด คนที่อยู่ในระยะ Wi-Fi สามารถดูภาพและกดถ่ายได้

เฟิร์มแวร์เปิด `CANOPY_AI_ENABLED=1` และใช้หัวไฟล์ `Trakan-project-1_inferencing.h` ติดตั้ง `../model/plant_fomo_int8_arduino_v2.zip` ผ่าน Sketch → Include Library → Add .ZIP Library ก่อนกด Verify ไฟล์ `build_opt.h` ปิด ESP-NN เพื่อหลีกเลี่ยงการรีสตาร์ตระหว่างรันโมเดลบนบอร์ดที่ทดสอบ หากต้องการคอมไพล์เฉพาะส่วนถ่ายภาพ ให้ตั้ง `CANOPY_AI_ENABLED=0` ใน `canopy_ai.h`
